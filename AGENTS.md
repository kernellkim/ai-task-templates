# Working agreement for this repository

This is a timed assessment task. Be efficient with tokens and keep every step reviewable.

## Before coding
- Restate the task in 3-5 lines and list open questions. Ask me before guessing.
- Record what we agree on in `AGREEMENT.md` (goal, scope, out of scope, acceptance criteria).

## While coding
- Work in small steps. After each step: run it or its tests, then commit with a meaningful message.
- Build the thinnest end-to-end version first, then deepen the core feature.
- Do not add dependencies unless necessary. Say why when you do.
- Never write secrets, API keys, or personal data into files.
- Do not claim something works unless you ran it. Say "not verified" otherwise.

## Explain as you go
- After each change, give a short summary: what changed, why, and how to check it.
- When there is a real choice between options, add one entry to `DECISIONS.md` (decision, alternatives, reason).

## Before finishing
- Update `README.md` (how to run, what is done, known limits) and `HANDOFF.md` (state, risks, next steps).
- Write these documents in Korean unless I say otherwise.
- Do not run `git push`. Do not change the Codex version.
